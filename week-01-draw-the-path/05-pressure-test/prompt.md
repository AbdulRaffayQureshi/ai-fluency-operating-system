# Pressure-Test Prompt

**Date:** 2026-07-25
**Model:** Claude Sonnet 5

---

## Prompt Sent

You are a skeptical senior UX strategist and portfolio reviewer. I am not looking for praise; I want you to find weaknesses.

**My Claim:** I build production-ready AI, machine learning, and web applications backed by reproducible code, rigorous data contracts, and clean UI architecture.

**My One Action:** Drive visitors to review my case studies and book a project consultation.

**My Sitemap:**
1. Hero - States claim, CTA to Case Studies
2. Work/Case Studies - 2-3 projects with metrics proving production-ready ML + web apps
3. About - Short trust-building bio
4. Contact - Calendly/booking form for project consultation

**Your Task:** Pressure-test this sitemap against my claim and one action.
- Does every page earn its place?
- What am I missing that would strengthen belief?
- What should I cut?
- Is the flow from landing -> believing -> acting frictionless?
- Be critical. If something is weak, say so.
